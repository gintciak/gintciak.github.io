Исследовательская задача

Работа посвящена планированию сроков проектов с взаимозависимыми задачами, ограниченными ресурсами и неопределёнными условиями выполнения. Авторы рассматривают, как сравнивать календарно-сетевые графики, если руководителю нужно учитывать сразу несколько критериев, например срок реализации, затраты, риски и состав команды.

Подход и методы

В предложенной последовательности сначала задаются показатели и строятся сетевые графики, отражающие зависимости между работами. Сценарии выполнения проекта генерируются методом Монте-Карло. Далее по значениям выбранных показателей выделяются недоминируемые сценарии. Процесс завершается оценкой сходимости, которая предназначена для отслеживания изменений качества найденного множества при продолжении поиска.

Результаты

Основной результат доклада представляет собой структуру стохастической многокритериальной оптимизации календарно-сетевых графиков. На итоговой схеме связаны выбор критериев, представление работ в виде графа, получение вариантов, сравнение альтернатив по Парето и оценка целесообразности дополнительных вычислений. В работе описано назначение каждого из этих этапов.

Практическое значение

Структура подходит для проектирования расчётного инструмента при управлении сложными проектами. Руководитель может задать критерии, соответствующие проектной ситуации, и использовать отобранные графики для сравнения возможных компромиссов между сроками, затратами и ресурсными ограничениями.
