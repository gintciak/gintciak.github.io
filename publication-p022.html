Интеллектуальный анализ данных для прогнозирования распространения инфекции

Alexey I. Borovkov, Marina V. Bolsunovskaya, Aleksei M. Gintciak

Alexey I. Borovkov, Marina V. Bolsunovskaya, Aleksei M. Gintciak. Intelligent Data Analysis for Infection Spread Prediction // Sustainability. 2022. Vol. 14. No. 4. Article 1995.

Страница публикацииDOIПолный текст

Исследовательская задача

Для прогноза заболеваемости на уровне региона важно определить, какой детализации данных достаточно. В исследовании проверено, даёт ли использование исходных индивидуальных записей преимущество для укрупнённой системно-динамической модели распространения COVID-19.

Подход и методы

Авторы сопоставили прогнозы для Санкт-Петербурга на основе двух наборов данных. Один был собран и обработан в агрегированном виде, другой сформирован на основе индивидуальных записей. Для расчётов использована модификация модели SEIR с группой находящихся на карантине. Она позволяет учитывать региональные меры ограничения контактов. Сравнение выполнено для оценок текущего числа заражённых на выбранном временном интервале.

Результаты

В описанном эксперименте результаты показали достаточность агрегированной информации для рассматриваемого класса моделей. Это заключение относится к конкретному уровню агрегирования и используемой постановке. В статье обсуждается, как вакцинация, повторные случаи заболевания и особенности поведения населения могли бы изменить требования к расширенной модели.

Практическое значение

Результаты помогают выбирать данные для регионального прогнозирования. Если укрупнённая модель отвечает исследовательской задаче, ограничение входных данных агрегированными показателями снижает потребность в обработке персональной информации.
