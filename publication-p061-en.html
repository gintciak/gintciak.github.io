Data Storage and Statistical Data Processing Tools for Solving the Tasks of Managing Regional Innovation Systems

Gintciak A.M., Skhvediani A.E., Fedyaevskaya D.E., Burlutskaya Z.V., Rodionova M.A.

Bibliographic citation

Gintciak A.M., Skhvediani A.E., Fedyaevskaya D.E., Burlutskaya Z.V., Rodionova M.A. Data Storage and Statistical Data Processing Tools for Solving the Tasks of Managing Regional Innovation Systems // Sustainable development and engineering economics. 2023. Vol. 4. pp. 8–19.

Publication pageDOIFull text

Research problem

Analysis of regional innovation systems brings together data from different areas, time periods and sets of indicators. The data store must support calculations and visualization within a digital platform while keeping the records consistent as different users work with them.

Approach and methods

The authors began by reviewing the input data and the operations needed by the platform components. They moved from a conceptual schema and entity-relationship diagram to logical and physical models. PostgreSQL was selected for implementation. The paper describes the organization of the data, the query structure and the requirements for data integrity.

Findings

The study presents a software implementation of the platform’s data storage and processing component. Its design accommodates the different combinations of input parameters needed for calculating innovation indicators. The storage structure also anticipates the addition of data for other calculation methods. Integration with a calculation and simulation experiment module is identified as a subsequent development.

Practical relevance

The system organizes data for regional comparisons and prepares it for scenario analysis. Other applications can make use of the design procedure and overall architecture, with the schema and queries adapted to the indicators used in the new domain.
