Сборник конференции

Исследовательская задача

Для поиска глобального экстремума нелинейной или мультимодальной функции одной переменной применяются разные стохастические алгоритмы. Работа систематизирует различия между процедурами поиска, чтобы сравнивать методы по свойствам, существенным для задачи.

Подход и методы

Авторы рассматривают базовую случайную выборку, адаптивный случайный поиск, имитацию отжига, метод случайных переходов между областями локальных экстремумов (basin hopping) и метод перекрёстной энтропии. Сопоставление выполняется по направленности поиска, способу использования данных предыдущих итераций и сложности настройки параметров.

Результаты

Выделены семейства методов случайной выборки, локально-глобального поиска с вероятностным принятием переходов и адаптивной подстройки распределения. По использованию накопленных результатов различаются независимые испытания, локальная адаптация, учёт траектории поиска и обновление по статистике выборки. Классификация показывает, в какой части процедуры конкретный алгоритм использует информацию предыдущих вычислений.

Практическое значение

Схема пригодна для предварительного выбора семейства алгоритмов и постановки сравнительного вычислительного эксперимента. Она позволяет явно фиксировать требования к направленности поиска, объёму настройки и использованию уже полученных оценок целевой функции. В таком эксперименте можно сопоставить методы с разной степенью адаптации параметров в одинаковых условиях поиска.
