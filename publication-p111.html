Исследовательская задача

Планирование разработки программного обеспечения осложняется непредсказуемой продолжительностью задач и конкуренцией за исполнителей одного профиля. В работе исследуется, как выбор резерва времени для отдельных работ влияет на общий срок, вероятность соблюдения заданного ограничения и простои сотрудников.

Подход и методы

Проект представлен ориентированным графом, в котором вершины соответствуют задачам, а связи задают зависимости выполнения. Для задач задаются распределения длительности, по которым рассчитываются календарные планы на основе выбранного процентиля. Моделирование методом Монте-Карло даёт распределение срока завершения проекта и оценки простоев при разных параметрах планирования.

Результаты

На примере проекта с предельным сроком 290 дней исследованы изменения ожидаемой длительности, вероятности соблюдения срока и простоя. Авторы наблюдали диапазон близких вероятностей с последующим резким снижением. В этом примере выбран 74-й процентиль как компромисс для составления календарного графика. Выбор относится к условиям рассмотренного проекта.

Практическое значение

Метод даёт руководителю способ сравнить планы по риску превышения срока и использованию времени сотрудников. Для применения необходимы зависимости между работами, данные о ролях исполнителей и оценки неопределённости длительностей.
