Labor Resource Balancing Algorithms in Project Portfolios Based on a Multi-Agent Approach

Бекетов С.М., Дергачев М.В., Гинцяк А.М., Шарко П.А.

Bibliographic citation

Бекетов С.М., Дергачев М.В., Гинцяк А.М., Шарко П.А. Алгоритмы балансировки трудовых ресурсов в портфеле проектов на основе мультиагентного подхода // Информационные технологии и вычислительные системы. 2026. № 1. С. 145–153.

DOILibrary record

Research problem

Concurrent projects compete for workers with the same skills. Reallocation decisions need to reflect individual deadlines and the overall performance of the portfolio. The paper studies a procedure in which projects can negotiate exchanges of staff within portfolio-wide resource constraints.

Approach and methods

Each project is represented as an autonomous agent with a belief, desire, and intention (BDI) architecture. The agent evaluates the utility of transferring or receiving labor resources using its local requirements and available information about the portfolio. The algorithms generate project start times stochastically and construct Pareto fronts for duration and labor requirements.

Findings

Using data from five projects, the authors compare scenarios before and after balancing. Portfolio completion time fell by 7.7% and labor requirements by 9.2% in the modeled case. The example shows how resource exchanges affect portfolio indicators as well as workforce utilization. The numerical results refer to that computational experiment.

Practical relevance

The procedure helps managers compare reallocation options. It can be used to assess the local utility of an exchange and select a portfolio-level trade-off between project durations and labor requirements.
