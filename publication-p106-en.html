Service-Oriented Architecture in the Design of an Organization’s Digital Ecosystem

Поспелов К.Н., Аблавацкая Д.А., Ракова В.В., Гинцяк А.М.

Bibliographic citation

Поспелов К.Н., Аблавацкая Д.А., Ракова В.В., Гинцяк А.М. Сервис-ориентированная архитектура в проектировании цифровой экосистемы организации // Вычислительные технологии. 2026. Т. 31. № 1. С. 121–135.

Publication pageDOI

Research problem

Organizations often carry out calculations across applications and repositories that use different formats and interfaces. These calculations may have to run in a particular order and exchange intermediate results. The research formulates the problem of integrating existing and new components into a digital ecosystem with coordinated data exchange.

Approach and methods

The authors separate the application into functions provided by independent services and design a structure for their interaction. The prototype uses Python and REST application programming interfaces (REST APIs). A central configuration module controls calls to other components, processes the information returned, and coordinates transfer between subsystems.

Findings

A prototype consisting of three external applications and one central control module was implemented and tested on a calculation workflow. The paper describes how the components are connected, what the configuration module handles, and how results from disparate sources are combined into a single output.

Practical relevance

The architecture can inform similar integration tasks in which independent applications need to exchange information within a common workflow. It helps define service boundaries, data transformation requirements, and the function of a central coordinating component. The particular interfaces would depend on the applications in use.

Research areas

  • Intelligent decision support systems
  • Digital modelling of production systems

Keywords

service-oriented architecture, digital ecosystems, application integration, data exchange, REST API
