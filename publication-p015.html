Исследовательская задача

В медицинском учреждении учёт и диагностические обследования могут обслуживаться разными системами. Когда назначение исследования или изменение данных пациента приходится переносить между ними вручную, возникают задержки и ошибки ввода. Работа рассматривает интеграцию, необходимую для согласования этих процессов.

Подход и методы

Авторы описывают проект связи медицинской и диагностической информационных систем через независимую платформу Mirth Connect. В ней настраиваются правила получения, преобразования и передачи сообщений. Интеграция предусматривает передачу назначений, подготовку рабочих списков для диагностического оборудования и синхронизацию изменений идентификационных данных. Рабочий список содержит сведения, которые диагностическое оборудование получает для выполнения назначенного пациенту обследования.

Результаты

После реализации платформа стала передавать новые назначения в систему диагностики. Обновление данных пациента в медицинской системе автоматически отражалось в связанной системе. Описанная реализация позволила настраивать обмен на промежуточной платформе, сохраняя существующий код и конфигурацию целевых систем.

Практическое значение

Результат полезен для организации обследований и устранения повторного ввода сведений. Статья показывает, какие данные нужно согласовать, чтобы назначения и диагностические рабочие списки формировались из общей актуальной информации.
