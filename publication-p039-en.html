Structural Division of Strategic Interactions on Various Grounds

Зубкова Д., Гинцяк А.

Bibliographic citation

Зубкова Д., Гинцяк А. Структурное разделение стратегических взаимодействий по различным признакам // Управление инновациями в условиях цифровой трансформации: Материалы Всероссийской студенческой учебно-научной конференции. 2023. С. 98–102.

DOILibrary record

Research problem

In formalizing a management problem, identifying the properties of an interaction helps determine which game model to use. The authors examine how to describe a game using a set of attributes and apply the description to interactions among project stakeholders.

Approach and methods

The paper reviews publications from Scopus and the Russian Science Citation Index. It compares attributes such as the number of players and strategies, the possibility of cooperation, move order, the form of the game, information availability, symmetry, payoffs and the duration of the interaction. Brief explanations accompany the possible values of these attributes. A single interaction can be described by several attributes, such as the sequence of moves and the possibility of forming coalitions.

Findings

The authors apply the framework to a project run using Scrum. They characterize the example as an interaction involving multiple players, a finite set of strategies, sequential moves and non-zero-sum payoffs. The example shows how selecting values for the attributes produces a concise description that guides subsequent formalization.

Practical relevance

The classification can be used when designing games for project management. It helps state assumptions about roles, information and the order of actions before constructing a game tree or choosing another formal representation.

Research areas

  • Project and portfolio management
