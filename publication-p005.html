Исследовательская задача

В центре работы находится организация проектной команды с несколькими группами специалистов, которые совместно разрабатывают комплекс для прогнозирования сбоев систем хранения данных. Исследуемый вопрос состоит в том, как рассмотреть реальное взаимодействие участников вместе с иерархией управления и сравнить возможные изменения структуры команды.

Подход и методы

Граф строится по связям участников в ходе профессиональной деятельности. Расчёт размера и плотности сети показывает её общую связность, а центральность узлов даёт сведения о распределении коммуникаций. Предлагается использовать социометрические опросы и анализ командных ролей для изучения межличностных отношений. Оценки целостности и автономности опираются на информационный подход А. А. Денисова.

Результаты

В рассмотренной группе у каждого участника есть рабочая связь с коллегой. Несколько наиболее связанных узлов приходятся на участников, которые координируют работы. Сопоставление исходной схемы и расчётной альтернативы показывает, как изменение числа помощников руководителя влияет на оценку автономности. В качестве примера для расчёта выбрана группа специалистов, работавшая в СПбПУ.

Практическое значение

Анализ применим при проектировании рабочих связей в распределённых командах. Он даёт руководителю основания для обсуждения централизации и распределения координационных функций.
