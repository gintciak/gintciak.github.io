Digital Platforms for Analysis and Forecasting the Innovative Development of the Regions

Кухоткин И., Гинцяк А., Егоров Д., Бурлуцкая Ж., Жидков Д.

Research problem

Regional innovation data must be made comparable, stored and presented in a form that supports analysis. This paper specifies what a digital platform needs to let users explore data for Russian regions, examine changes in indicators and eventually run scenarios.

Approach and methods

The authors reviewed existing applications for processing and presenting innovation data. They drew up requirements for data storage, calculations, reporting and visualization. NestJS and PostgreSQL were selected for the server and database, with Next.js proposed for the user interface. The planned visual tools include an interactive map, charts and tables.

Findings

The paper reports a database design for indicators collected over several years. It explains how data storage fits into the larger platform and how users would retrieve or update records. The simulation component and the use of predictive and prescriptive analytics are identified as subsequent work.

Practical relevance

The requirements provide a starting point for a system that presents source data and derived indicators in a common interface. The structure helps prepare the data needed to compare regions and, once the analytical module is in place, evaluate proposals affecting their innovation systems.
