Multi-Agent Approach to the Redistribution of Labor Resources Within the Formed Project Portfolio

Бекетов С.М., Шарко П.А., Гинцяк А.М.

Bibliographic citation

Бекетов С.М., Шарко П.А., Гинцяк А.М. Мультиагентный подход к перераспределению трудовых ресурсов внутри сформированного портфеля проектов // Материалы XII Международной научно-практической конференции "Интеллектуальная инженерная экономика и индустрия 6.0" (ИНПРОМ-2025). 2025. С. 444–447.

eLIBRARY record

Research problem

Once a project portfolio has been approved, demand for specialists changes as work progresses. This paper examines reallocating staff between active projects that can communicate directly and have information about their team composition and workload.

Approach and methods

Each project is represented as an autonomous agent. Its beliefs in the belief-desire-intention architecture include team composition and labour requirements. At each iteration, agents recalculate labour requirements, evaluate possible transfers of team members and communicate transfers through a distributed message pool. The process stops when available transfers cease to reduce total portfolio labour requirements.

Findings

The authors present a multi-agent system design and an algorithm for project agents. These specify how team data are updated, how the effect of a transfer on multiple projects is considered and how resulting team sizes are obtained. The paper proposes the hybrid JAM architecture for implementation and identifies implementation and testing on live portfolio data as future work.

Practical relevance

The algorithm provides a basis for designing support for staffing decisions between existing projects. It makes total portfolio labour requirements an explicit criterion for evaluating proposed changes to local teams.
