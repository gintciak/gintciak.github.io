Исследовательская задача

При распределении сотрудников между параллельными проектами решения на уровне отдельных команд влияют на реализуемость портфеля. Метод должен учитывать доступность специалистов нужного профиля, различия в сроках и трудозатратах, а также неопределённость этих оценок. Авторы исследуют, как связать выбор проектных команд и последующую корректировку загрузки сотрудников.

Подход и методы

Метод строится на двух уровнях оптимизации. Для каждого проекта составляют сетевой график, оценивают трудоёмкость задач и генерируют допустимые варианты состава команды. По рассчитанным срокам и трудозатратам получают фронт Парето и оценивают его сходимость. Варианты отдельных проектов объединяют с учётом ресурсных ограничений портфеля. После выбора общего сценария выполняют динамическое перераспределение для выравнивания загрузки.

Результаты

Работоспособность последовательности продемонстрирована на портфеле из четырёх проектов по разработке мобильных приложений. Для них построены отдельные фронты Парето, затем получен фронт портфеля с учётом вариабельности оценок. На выбранном сценарии показано изменение графиков загрузки до и после балансировки.

Практическое значение

Руководитель портфеля получает несколько сценариев, различающихся сроками, трудозатратами и потребностью в персонале. Метод предназначен для проектов с каскадной организацией работ. Для его применения необходимы сведения о зависимостях задач, доступности работников и разбросе трудоёмкости.
