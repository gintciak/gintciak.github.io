Исследовательская задача

Сценарный анализ стохастической имитационной модели требует многократных прогонов и становится дорогим при росте числа управляющих параметров. Работа рассматривает, как сократить число вычислений при поиске эффективной конфигурации.

Подход и методы

Предложен контур, в котором имитационная модель даёт данные для обучения суррогатной модели на основе гауссовских процессов. Оптимизатор оценивает управляющие параметры по прогнозу суррогатной модели. Новые прогоны назначаются в областях недостаточной точности аппроксимации. Метод роя частиц используется при поиске областей для дообучения. Качество прогноза оценивается среднеквадратичной ошибкой и коэффициентом детерминации.

Результаты

Схема проверена на дискретно-событийной модели маршрута наземного пассажирского транспорта. Во всех оценённых показателях ошибка аппроксимации стабилизировалась примерно после 100–120 точек обучения. Авторы сообщают о сокращении числа прогонов относительно прямого перебора при сопоставимом качестве конфигурации. Эксперимент проведён на одной модели с двумя управляющими параметрами.

Практическое значение

Архитектура применима как надстройка, которая обменивается с имитационной моделью входными параметрами и выходными показателями. Для переноса на системы большей размерности и сравнения с другими способами оптимизации нужны отдельные эксперименты с расширенным набором сценариев и параметров.
